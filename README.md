BCD Arithmetic Mini-Processor

Project Overview

A digital electronics project designed and simulated using Proteus Design Suite. The Mini-Processor performs three arithmetic operations on two single-digit BCD (Binary-Coded Decimal) inputs: Addition, Subtraction, and Multiplication.

Features
- BCD input handling using 4-bit inputs.
- Addition using Half Adders and Full Adders.
- Subtraction using 2's complement logic.
- Multiplication using shift-and-add logic.
- Multiplexer-based operation selection.
- Binary-to-BCD conversion.
- 7-segment display interfacing using 4511 decoder ICs.

Operation Selection
- 00 – Addition
- 01 – Subtraction
- 10 – Multiplication

Tools Used
- Proteus Design Suite
- Digital Logic Design

Repository Contents
- Proteus/ – Original Proteus simulation files.
- Screenshots/ – Images of the circuit design and simulation results.
- Report/ – Project report in PDF format.

Simulation

The project was simulated using Proteus to test the three arithmetic operations. Images of the circuit design and simulation outputs are included in the repository.
